About

Not much is known about BookWorm for the Xbox Live Arcade. It was released on Aug 26, 2005. This version doesn't change much from the PC version of BookWorm Deluxe. The Xbox version uses some of the image files used in the Flash version. Though it was only available to Xbox Live Members ($9.99), the archived files are still playable on an emulator. For some reason this port of the game does not accept words such as "gay", or "queer", but it is Microsoft, the king of censorship. Instructions to play this BookWorm are below.

Installation Instructions

  1. Download the Xbox emulator included with BookWorm
  2. Unzip the file and open Xemu
  3. In Xemu, click on settings and go to "System"
  4. In System, we're going to need to configure a few things, but this'll only take a minute!
    • -
    • 1. Set System Memory to 128 MiB
    • 2. Link files to their corresponding directories:
    • 3. MCPX Boot ROM - mcpx_1.0.bin
    • 4. Flash ROM (BIOS) - Complex_4627v1.03.bin
    • 5. Hard Disk - xbox_hdd.qcow2
    • 6. EEPROM - eeprom.bin
  5. Save and Restart Xemu
  6. Insert the "Xbox Live Arcade Final" disk file and wait for the Arcade to load
  7. Click on BookWorm, and have fun!
